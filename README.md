CYBER // SNAKE: PROTOCOL 2099

A futuristic Snake arcade experience built with HTML5, CSS3, and Vanilla JavaScript.

Features

* Futuristic cyberpunk interface
* Neon graphics and animations
* Multiple game modes
* Dynamic power-ups and special abilities
* Procedural sound effects and synthwave music
* Achievements and high-score tracking
* Desktop and mobile controls
* Responsive design

Technologies

* HTML5
* CSS3
* JavaScript
* Web Audio API
* HTML Canvas
* LocalStorage

How to Play

* Use Arrow Keys or WASD to move.
* Press Space to activate Turbo Boost.
* Press P or ESC to pause.
* Collect energy cores to increase your score.
* Avoid obstacles and collisions.
